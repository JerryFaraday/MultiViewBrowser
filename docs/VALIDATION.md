## Electron专项脚本

先运行npm run build。脚本会启动Electron并写入本地生成报告，部分需要GUI或网络；运行前检查脚本采用的临时配置与测试页面，不应混用真实私人会话。

| 命令                                | 验证对象及局限                                                                                  |
| ----------------------------------- | ----------------------------------------------------------------------------------------------- |
| node scripts/ui-smoke.mjs           | 默认最大化、分屏、浮窗、分辨率、收藏、拖动UI；含DOM合成鼠标事件，不等于全系统鼠标人工验收       |
| node scripts/audio-smoke.mjs        | 本地媒体与iframe的页面音量、总增益、静音、恢复及信号幅度                                        |
| node scripts/popup-smoke.mjs        | 链接当前页导航、中键空槽分配和满槽忽略                                                          |
| node scripts/drag-smoke.mjs         | 原生覆盖层可信Chromium拖放；实例保留、底层播放和站点元素无交互                                  |
| node scripts/log-smoke.mjs          | 正常生命周期、点击记录及网址/输入标记不进入操作日志                                             |
| node scripts/review-probe.mjs       | 故意展示旧写覆盖、静音和焦点缺陷，不是“必须全绿”的通过性验收                                    |
| node scripts/review-media-probe.mjs | 模拟媒体生命周期，展示同尺寸播放器交接缺陷                                                      |
| npm run smoke                       | 早期固定视口坐标探针，历史整体false；覆盖的是固定视口与坐标技术路径，不宜单独作为当前UI发布门禁 |
| node scripts/bilibili-smoke.mjs     | 直播首页音量专项，需要网络；不能替代具体直播间                                                  |
| node scripts/rooms-diagnostic.mjs   | 35/6/55号直播间诊断，需要网络且可能需人工验证码                                                 |

原始JSON与用户日志未纳入Git，报告中纯文本文件名只说明本地输出位置；重跑会覆盖同名结果，不代表历史结果永久可复现。

- V0.1.1.3：真实Electron computedStyle确认按钮/图标none，输入/备注text；空槽位文字已移除，UI回归通过。
- V0.1.1.2：缩放浮窗约300×240 DIP、底层网页visible且bounds不变；移入保持、移出隐藏。选择4K→放大实际2560×1440→还原4K，存储配置未被临时覆盖。150% DPI存在1 DIP舍入，几何断言容差2 DIP。
- 日志：真实点击、音量变化、正常关闭及隐私过滤通过。强制终止不保证session.end。
- 独立拖拽：视频/聊天区域投放各交换一次，iframe媒体继续播放，底层click/drop均为0；不等同于全Windows OLE路径完成验收。
- 同源iframe音频：页面25%/50%、反向75%同步；总音量50%时输入RMS约0.031858、输出约0.015929，幅度比约0.5。不能推广到跨域、DRM或所有站点自绘控件。
- 直播首页：旧专项报告读取到播放器五档和总增益0.25/0.5/0.75/1/1.5、context running；参数读回不能独立证明扬声器幅度正确。
