# 设置系统与固定规则

适用V0.2.1.0。入口为顶部“设置”，按六类组织。

## 审查结论与分层

| 层级 | 保存内容 | 生效范围 |
|---|---|---|
| 固定产品规则 | 交换、焦点、主副声音策略、按编号填空、链接路由、暂存拖放 | 不提供设置开关；沿用BrowserManager、AudioManager、SlotManager及DragOverlay |
| 全局用户偏好 | preferences；收藏栏显示仍复用bookmarksBar | 启动、外观、权限和新页面默认值 |
| 当前会话 | session、windowState | 当前布局/网页与退出窗口状态；窗口状态与网页内容分别恢复 |
| 命名工作区 | workspaces[].snapshot | 仍为用户手动保存，不因自动保存会话而覆盖 |
| 页面局部状态 | Page.scale、pageZoom、volume、audio | 已有页面与保留的暂存实例不被新页面默认值覆盖 |
| 暂存 | pageStash | 仍独立保存，不随空白工作区或手动工作区加载清空 |

旧配置缺少preferences时迁移为原体验：最大化、恢复会话（尊重旧restore=false）、自动保存开启、关闭不确认、1080p自动等比适配、Page Zoom 100%、重试关闭、分组名隐藏、深色UI 100%、文字提示开启、原蓝色、日志永久、站点权限默认拒绝。

## 常规

启动可选最大化、上次状态、普通窗口。“上次状态”保存正常窗口大小/位置、最大化及F11全屏状态；离屏位置会按当前显示器工作区修正。恢复内容可选上次会话、指定命名工作区或空白工作区。未指定/已删除的默认工作区回退空白，不删除收藏、命名工作区或暂存。

关闭自动保存会话后，ConfigStore仍保存偏好、收藏、命名工作区及暂存，但磁盘session保留开关关闭前最后一次已保存快照，运行时继续使用内存会话。开启时延续原有运行期间保存和退出保存。正常退出先向界面请求最后修改，再保存窗口状态；渲染器无响应时2.5秒回退最后已确认的状态。关闭确认按从不/多个页面/始终，计数包括暂存。命名工作区仍需用户手动保存。

## 网页浏览与收藏栏

新页面默认分辨率1080p/1440p/4K、现有自动等比适配或响应式、Page Zoom 25%–500%。只在创建新Page时应用；已有页面及工作区快照不回写。Ctrl+0仍固定恢复100%，主窗口内部放大仍按原规则临时2K，均不是可配置项。

重试默认关闭，开启可选1–10次，仅对主文档网络加载失败进行间隔递增重试，不重试取消导航、HTTP错误页面或验证码；导航更换和页面关闭取消旧重试。收藏栏显示复用原开关，新增分组名显示，分隔线及排序规则不变。

## 外观

深色/浅色/跟随系统只改变应用UI，不强迫网站使用相同主题。UI缩放90%/100%/110%/125%与页面Page Zoom独立；主进程按物理DIP接收经过preload换算的矩形，音量、缩放、暂存和缩放反馈浮窗跟随UI比例，拖放遮罩保留原生坐标。文字提示开关不会关闭固定的悬停操作面板。强调色提供蓝、青绿、紫色预设。

## 数据与隐私

导出完整配置含网址、名称、偏好、站点权限、会话与暂存；不含Cookie、网站存储或日志正文。导入可选全部、仅用户偏好（含收藏栏可见性及站点权限）、收藏及分组、命名工作区及布局；验证JSON后再次明确确认覆盖范围。全部导入属于显式覆盖，会更新已保存会话，即使自动保存关闭；局部导入不替换其他分层。

打开配置目录与日志目录使用实际运行路径。日志默认永久，可选7/30/90天；启用有限保留期需确认并清理超期文件。手动清理需再次确认，仅处理已知日志文件，保留当前日志及可识别的仍在运行进程日志，不能删除的文件跳过。不扫描或删除配置、Cookie、工作区和站点存储。清缓存也需确认，仅调用共享浏览会话clearCache清理HTTP资源缓存；不清Cookie/localStorage/IndexedDB，不刷新页面。

网站权限只开放本次明确要求的HTTPS摄像头、麦克风、通知；未配置和其他权限仍拒绝。按请求frame的origin检查，子域不自动继承。撤销会确认并重新加载相关页面以停止已有会话，未保存输入可能丢失；不删除登录数据。实际使用仍受操作系统授权和网站安全策略约束，未进行真实设备录制验收。

## 关于与诊断

完整版本来自version.json；展示实际Electron/Chromium/Node版本。检查更新只查询GitHub正式Releases并比较四段版本，不后台自动检查、不下载或安装。仓库、发布页和独立用户手册在系统浏览器打开。诊断导出采用白名单，只包含运行版本、平台架构、数量和有限枚举/数值偏好，不包含网址、页面标题、名称、权限站点、用户目录、Cookie、凭据和日志正文。

实现入口：src/components/SettingsPanel.tsx、src/core/Preferences.ts、electron/SettingsService.ts、electron/storage.ts。权限API参考[Electron Session文档](https://www.electronjs.org/docs/latest/api/session)。
