# 收藏栏开关依赖与禁用视觉

日期：2026-11-15；版本：V0.2.5.2。仅调整收藏栏三个子开关的依赖、保留值及视觉，不变更收藏、检测算法或其他设置布局。

## 实现

- `Preferences.ts`集中定义showGroupNames/showBookmarkGroups/liveDetection及依赖判断。SettingsPanel统一生成真实disabled，checked始终读取原偏好；前端更新函数重查父状态，ConfigStore.accept以同一列表保护已隐藏时的值。SettingSwitch内部也显式拦截disabled回调。
- 删除UI关闭bar时写liveDetection=false及configSchema的强制清除。持久化值与可交互状态分离，重启也保持原值；实际bar显示和两平台任务仍使用原有父开关门控，隐藏时不继续查询。已被旧版清除的历史值无法推断，本次保护当前保存值。
- 复用现有SettingSwitch：保留40×22px尺寸、原始背景和checked位置，opacity=1，disabled伪元素蒙层rgba(128,128,128,.38)。禁用光标default，覆盖普通hover/pressed反馈；恢复后伪元素消失，原视觉自动恢复。行高和间距未改。
- `.setting-row:has(> .setting-switch:disabled)`只为对应名称/说明提供统一主题派生灰色文字，维持可读性，不降低整行透明度。默认蓝色开启态与灰色关闭态仍区分，其他强调色也保留原色与蒙层。
