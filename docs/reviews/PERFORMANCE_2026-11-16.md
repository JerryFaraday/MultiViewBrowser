## 调查与实现取舍

1. **全屏权限**：共享会话的通用权限处理器只放行已配置的设备/通知权限，误拒绝 fullscreen。只放行 Chromium 正常手势约束下的 fullscreen，不放行 automatic-fullscreen。WebContentsView 使用 disableHtmlFullscreenWindowResize，主进程决定哪个当前槽位需要显示器全屏；辅助槽位不调整顶层窗口。独立探针验证设备模拟中的 Fullscreen API 本身有效。
2. **输入捕获**：小型原生预览窗首次显示会中断 Windows Pointer Capture。最终使用专用透明原生拖动层收集移动/松手，隐藏网页实例不参与此过程；网页继续运行，仅暂时隔离输入。绘线使用同一强调色，不通过拉伸网页伪造预览。新增 preload 同步纳入构建和打包清单。
3. **暂停恢复**：逐个 WebFrameMain（包括跨域框架）执行固定脚本，记录策略开始前正在播放的HTML媒体。叠加“设置”和“放大”原因；只在全部原因消失后恢复原媒体、原来源。期间可信用户输入、额外暂停或媒体来源变化会放弃自动恢复；播放失败只尝试一次。新文档只应用当前策略，不恢复旧文档对象。
4. **安全释放**：只评估长期暂存页，不释放可见槽位。可信输入、表单/可编辑元素、iframe、活动HTML媒体/流、可听音频、加载中或检查失败均保留。最后调用尊重 beforeunload 的关闭API，退出保护可否决关闭。单次定时到期后，失败评估至少间隔5分钟，普通配置更新不绕过冷却。未强制销毁所有到期页面。
5. **标题**：默认不请求；开启时最多一个在途、8秒超时、约512 KiB上限、无凭据、无JS、不重试。已有热页面标题直接使用；结果写回前核对条目仍存在、URL相同和功能仍启用。
6. **日志与退出**：单次运行近16 MiB容量上限，超限停止普通记录，保留容量摘要和结束记录；不能承诺容量受限时记录无限操作。序号、末次时间及合并次数保留顺序信息。只有异常进程退出使用同步兜底；正常关闭先等待配置和日志异步冲刷。所有操作数据仍经过原隐私白名单。
7. **斗鱼工作进程**：20次无网络的进程启动/参数检查，中位8.96 ms、P95 13.08 ms。未证明相对30–1800秒轮询周期有足够收益，保留现有外部工作进程及取消逻辑，不贸然改常驻架构。

## 性能方法和原始数据

运行 `node scripts/performance-smoke.mjs` / `--after`。同一 Windows 机器、Electron 45，隔离 profile，静音；4个本地页面每30ms替换一个DOM节点，媒体使用canvas captureStream模拟两视频/两直播；不是网络站点或真实解码性能基准。最大内置/有效布局为9槽；热暂存场景4可见+20保留。

每阶段3个一秒CPU/工作集采样；CPU数值来自 Electron getAppMetrics 的百分比，渲染进程合计。内存为进程工作集相加，可能重复计算共享页，不是私有物理内存。GPU为本应用PID的Windows GPU Engine计数器最大引擎采样，不是整卡利用率；0/1低分辨率采样不能证明GPU降低。媒体scan次数通过一个视图的精确覆盖计数获得；**未单独测量函数处理耗时**。计数挂钩只在测试入口，不进入正式应用。

详细测量表见下方最终数据；报告区分API计数、调用耗时及真实画面，不把setBounds完成等同屏幕完成重绘。短时CPU样本存在波动，部分渲染CPU样本更高，**不据此宣称整体CPU/GPU显著下降**。确定性收益主要是等价调用和同步写盘消除；热暂存默认不释放，因此不预期默认20页内存大幅降低。

## 验证范围和技术限制

- 单元：268项通过（含旧配置默认值、合并保存/备份、日志顺序/隐私、DOM更新不重复整页查询、媒体恢复和用户干预）。类型、构建、格式检查见最终交付记录。
- 原生：资源策略、10次全屏进退、1440p/4K与80%/125% Page Zoom、跨域iframe全屏/暂停/恢复、主副角色交换、F11独立、实例标记、释放后重载及输入/beforeunload保护通过。
- UI：新增设置实际操作、内存/磁盘一致、隐藏子参数保留、实时/预览拖动中不写盘、松手落盘、125% UI坐标通过。设置布局在1080p/1440p/4K和模拟DPI/800×600/640×420通过；已查看真实设置截图。模拟DPI不是所有真实多显示器验收。
- 既有：交换6种实际焦点/实例、拖动网页持续播放且不接收站点输入、暂存排序/关闭/交换/标题、缩放反馈/Canvas/iframe输入、设置/数据保护、直播检测调度及正常关闭日志隐私回归通过。
- 实站全程静音：Bilibili视频 BV1m7WB6mEuM 和斗鱼1667826存在播放中video；API全屏后主槽2560×1440、副槽650×700，媒体仍处于播放状态。此处通过的是实际页面上的原生Fullscreen API，不冒充所有网站播放器按钮的人工验收。
- B站直播1883358196、35、6加载页面及全屏几何有效，但均未生成video，原因未确认，**未验收真实直播流持续播放**。不以主页或页面能全屏替代播放验证。
- 后台节流：隐藏暂存页10ms计时器约1.2秒内开启执行1次、关闭执行120次；关闭时Chromium也报告document.hidden=false。这是内核行为，不能承诺同一BrowserWindow内各视图完全独立节流。活动媒体、可见窗口及Chromium节流豁免可改变效果。
- 暂存释放是保守启发式，无法保证任意网站自建状态、独立Web Audio、DRM或内存中编辑器都可识别；默认关闭，含iframe/输入等不确定页面保留。未进行数小时真实时间等待、断电恢复或硬盘故障注入。
- 自动暂停仅覆盖HTML媒体。网站自有音频引擎、直播重连、自动播放权限、脚本改写和跨域框架策略可能限制恢复；不重试到成功、不宣称通用播放器遥控。
- 固定逻辑视口的既有5E低倍率输入限制仍有效，没有通过自动切换响应式掩盖。

可复跑：`node scripts/resource-policies-smoke.mjs`、`node scripts/performance-ui-smoke.mjs`、`node scripts/fullscreen-sites-smoke.mjs`、`node scripts/page-zoom-smoke.mjs`、`node scripts/settings-layout-smoke.mjs`。测试结果和临时截图默认在被忽略的结果文件或out目录；不包含真实账号、Cookie、用户日志或浏览器资料。

Electron API依据：[WebContents](https://www.electronjs.org/docs/latest/api/web-contents)、[WebPreferences](https://www.electronjs.org/docs/latest/api/structures/web-preferences)。具体兼容性以本机Electron45的探针和回归为证，不把文档承诺等同全站点实测。
