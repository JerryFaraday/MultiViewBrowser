# MultiView Browser 软件使用手册

适用版本：V0.1.1.11。编写日期：2026-11-12。依据当前源码及界面文字编写；初次原生运行受本机 Electron 目录 ACL 阻断，后续已完成本地自动化换位、缩放、音频等探针；真实鼠标及网站兼容性尚未全面人工验收，相关限制见第十一节。本手册不把历史测试或代码实现视为所有网站均已验证。

## 一、软件简介

MultiView Browser 是面向 Windows 的多网页分屏浏览器。适合直播多路观看、网页资料对照、信息看板以及经常切换主次网页的场景。一个程序窗口中最多显示九个网页槽位，支持分屏比例调整、网页换位、独立内容缩放、页面及总音量控制、收藏分组和工作区。

所有网页共享登录会话。同一网站的登录状态可能在不同视图间共享，不提供每个窗口独立账号的隔离功能。主窗口是编号固定的第一个槽位，并不始终是面积最大的区域；其余称为2号至9号窗口。网页可以在这些位置之间交换。

## 二、安装与启动

### 2.1 已取得免安装构建

1. 将完整的 `win-unpacked` 文件夹放在可访问的位置，保留内部全部文件。
2. 双击其中的 `MultiViewBrowser.exe`。
3. 程序启动后默认最大化。首次使用默认为四宫格、没有网页、总音量100%。

若项目目录已有 `release/win-unpacked/MultiViewBrowser.exe`，也可双击根目录的 `Start-MultiViewBrowser.cmd`。该脚本只启动已有构建，不自动编译；只复制 exe 或只克隆源码均不足以启动。

仓库配置了 NSIS 安装包生成方式，但本轮没有生成或验证安装器，不假定已有公开下载地址。具体系统兼容范围与签名情况以实际交付包为准。

### 2.2 从源码运行（开发人员）

需要 Windows、Node.js 和 npm。在项目目录安装锁文件依赖后执行：

```powershell
npm ci
npm run dev
```

生产模式执行 `npm run build` 后执行 `npm start`。`npm run pack` 生成 Windows 目录构建，`npm run dist` 用于生成安装器。以上是使用说明，本轮审计没有安装依赖、修改版本或重新打包安装器。构建相关细节参见 [开发文档](DEVELOPMENT.md)。

## 三、主界面与第一次使用

| 区域       | 功能                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 顶部工具栏 | 布局、收藏夹、收藏栏、添加网页、总音量、放大主窗口、工作区、保存工作区及设置 |
| 收藏侧栏   | 搜索、选择打开位置、创建分组、添加和管理收藏                                 |
| 横向收藏栏 | 按分组顺序排列收藏，组间用竖线分隔；可在工具栏或设置中开关                   |
| 分屏区域   | 网页槽位、各网页地址栏与控制按钮、可拖动分割线                               |
| 底部状态栏 | 已打开网页数、共享会话提示、操作提示或错误消息；错误按钮可点击清除           |

点击空位中的“＋ 添加网页”，或顶部“＋ 网页”，先打开 Bilibili 直播首页，再在该网页上方地址栏输入目标网址并回车。顶部添加按钮使用当前可见布局中第一个空槽；没有空槽时显示提示，不自动扩大布局。空位按钮只在所在槽添加。

每个已加载网页的标题栏依次包含窗口编号拖动柄、后退、前进、刷新、地址栏、页面扬声器、缩放设置齿轮、关闭按钮。输入未带协议的域名时默认补全 HTTPS；仅允许 HTTP/HTTPS，地址栏不是搜索框。关闭网页保留空槽，其他页面不自动补位。

## 四、多视图布局与主副关系

点击“布局”选择缩略图，立即切换并关闭布局选择面板。内置16种布局：单窗口、左右双窗口、上下双窗口、上下三窗口、左右三窗口、左大右二、上大下二、四宫格、上下四窗口、左大右三、上大下三、六宫格、六窗口混合、八宫格、八窗口混合、九宫格。

拖动相邻区域间分割线可改变比例；嵌套布局按所拖分割线所在层级调整。极小窗口下不保证每个网页都保持足够操作面积。

切换布局保留现有网页及其编号。切换到较少槽位的布局后，多出的网页会隐藏，仍可能运行和播放；切回较大布局可再次看到。需要释放资源时，应回到能显示相应槽位的布局后逐一关闭网页，不能把隐藏等同于关闭。

“保存为新布局”只保存布局结构和比例。“恢复保存 / 默认比例”恢复当前所选内置布局的默认比例或自定义布局的已保存比例，不恢复网页、音量或内容缩放。自定义布局支持应用、覆盖、重命名和删除；删除或覆盖前请确认对象，部分操作没有额外确认步骤。

## 五、换位、焦点与主窗口放大

### 5.1 拖动换位

按住网页左上方“主、2、3”等编号拖动柄，将其拖到另一窗口标题栏、网页区域或空槽后松开。交换会保留网页实例及其页面内容缩放；目标为空时相当于移动。只有已加载网页能作为拖动来源。拖动期间网页继续渲染和播放，但覆盖层暂时接管拖放，底层站点不能交互；释放或取消后恢复。

焦点规则由交换完成后的原生视图显示更新执行：

| 操作                                     | 交换后的键盘焦点目标         |
| ---------------------------------------- | ---------------------------- |
| 主窗口与有网页的副窗口交换，不论拖动方向 | 新进入主窗口的网页           |
| 两个有网页的副窗口交换                   | 被拖动的源网页，跟随其新位置 |
| 副窗口网页移入另一个空副槽               | 被拖动的源网页，跟随其新位置 |
| 副窗口网页移入空主槽                     | 新进入主窗口的网页           |
| 主窗口网页移入空副槽，交换后主槽为空     | 原主网页，跟随其新位置       |

点击网页或其标题栏可更新选中槽位；收藏打开位置和外层界面缩放快捷键使用此选中槽位。以上规则已通过本轮6个本地自动化换位案例的原生焦点检查；真实鼠标全流程仍待人工验收。切小布局后可能保留已隐藏槽位的选中值，打开收藏前应在“打开位置”中重新选择一个可见位置。

### 5.2 双击留白和内部放大

双击副窗口网页外围的应用留白可与主窗口换位；副槽为空时把主网页移入该空槽。双击网页内容交给网站处理，不触发应用换位。响应式或铺满区域时可能没有可双击留白，应使用编号拖动柄。

点击顶部“放大主窗口”，或双击主窗口外围留白，可只显示主窗口；点击“恢复分屏”或再次双击相应留白恢复。放大期间临时使用2560×1440自动适配，齿轮设置锁定；恢复后还原原有适配设置。副窗口临时强制静音，主窗口仍服从原有静音、页面音量及总音量设置。

内部放大与 Windows 最大化、F11全屏是不同操作。F11不改变布局，Esc退出程序全屏；恢复分屏需使用“恢复分屏”。

## 六、网页导航、鼠标与键盘

后退和前进仅在该网页存在相应导航历史时有效，刷新重新加载当前网页。各视图分别操作，不同步鼠标、键盘或滚动。

普通左键链接保留网站自身处理，通常在当前槽打开；对于目标为新窗口的普通链接及非中键脚本弹窗，应用阻止独立窗口，并尝试在当前网页导航。Ctrl、Shift等修饰键点击不提供传统浏览器的新标签保证。

中键点击 HTTP/HTTPS 链接会尝试在当前布局编号最小的空槽打开；槽位满时忽略，不替换已有网页。Bilibili直播间左键打开数字用户ID的个人主页链接是特殊路径，也使用空槽并保留原直播；无空槽则忽略。跨域iframe及网站自定义脚本导航可能不经过这些捕获路径，需按实际网站验证。

| 操作              | 作用与目标                                               |
| ----------------- | -------------------------------------------------------- |
| Ctrl + 鼠标滚轮   | 调整接收滚轮事件网页的内容缩放；需将鼠标移到目标网页区域 |
| Ctrl + `+` 或 `=` | 放大当前获焦网页；外层界面获焦时使用选中槽位             |
| Ctrl + `-`        | 缩小同一目标网页                                         |
| Ctrl + `0`        | 将该网页内容缩放恢复100%                                 |
| F11               | 切换程序全屏                                             |
| Esc               | 程序处于全屏时退出全屏；不等同于恢复内部分屏             |
| 地址栏 Enter      | 打开输入的网址                                           |
| 总音量滑块方向键  | 滑块获焦时，向上/右增加、向下/左减少至相邻5%刻度         |

网页输入、滚动和站点快捷键由网页处理；与应用快捷键冲突时以上应用拦截规则优先。不将 Ctrl+L、Ctrl+T 等常见浏览器快捷键描述为本软件已实现功能。

## 七、网页独立缩放与适配

### 7.1 内容缩放

先点击目标网页或将鼠标移入其中，再使用上述缩放操作。每个网页的内容缩放独立保存，换位后跟随网页，不改变分屏容器大小。

支持25%、33%、50%、67%、75%、80%、90%、100%、110%、125%、150%、175%、200%、250%、300%、400%、500%档位；到达边界后不继续增减。Ctrl+0恢复内容缩放100%，不会重置分割线或齿轮里的视口设置。

操作时网页右上角短暂显示内核实际生效比例，停止约2秒后淡出。提示不抢焦点，鼠标可以穿透。对于Bilibili直播页嵌入特定5E组件的兼容路径，提示可能是自动适配与内容缩放的组合比例，因此Ctrl+0后不一定显示100%；内容档位仍被复位。

### 7.2 逻辑视口设置

悬停网页标题栏齿轮，移入弹出的小窗口修改；离开按钮与浮窗后自动关闭。修改立即生效。新网页默认1920×1080自动适配，分辨率预设另有2560×1440和3840×2160；旧配置的自定义尺寸会显示为原有设置。

| 模式               | 实际作用                                             |
| ------------------ | ---------------------------------------------------- |
| 自动适配（实验性） | 按固定逻辑分辨率完整缩放到容器内，可能出现留白       |
| 原生响应式（兼容） | 网页使用实际可用区域，站点按自身响应式布局显示       |
| 手动比例（裁剪）   | 按手动比例显示固定逻辑视口，超出容器的内容可能被裁剪 |

只有手动模式可修改比例（0.05–3）。主窗口内部放大时锁定临时2K设置，恢复分屏后才能继续编辑原设置。小视图中的复杂iframe点击异常时，可尝试响应式模式或放大主窗口；这不是所有站点兼容的保证。

## 八、音频播放和静音

默认自动策略为主窗口可出声、副窗口静音。悬停页面扬声器显示纵向音量滑块，可选0/25/50/75/100%。点击扬声器切换静音；从0%解除静音会将页面音量恢复100%。右键扬声器恢复自动主副静音策略，但不重置页面音量，0%仍无声。在浮窗选择非零页面音量也会将该网页设为可出声。

顶部总音量为0–150%，25/50/75/100%附近有吸附，当前比例在旁边显示。点击总扬声器静音，再点恢复保留的数值；拖动滑块或用方向键调整会解除总静音。总静音优先于页面设置。

网页换入主槽时恢复自动策略，并将0%页面音量恢复为100%；离开主槽时恢复副槽自动静音，保留页面音量值。副槽之间交换不重置各网页音频策略，因此已手动解除静音的副网页可以继续出声。无关网页设置不因换位重置。

对于可接入的HTML音视频，总音量通过增益作用于页面媒体，例如页面50%与总音量80%对应约40%的线性音量系数，并非主观响度百分比。跨域媒体、DRM、已有Web Audio图、跨域iframe或网站自有音频引擎不保证支持统一增益，150%不保证总能增强声音。

已知问题：旧播放器暂停但仍留在页面时，新播放器可能无法接管音量同步；网站程序化修改音量也可能解除页面静音。重要场景建议使用总静音兜底并检查实际声音，不依赖副槽自动策略作为绝对保证。

## 九、收藏、工作区与配置恢复

### 9.1 收藏

打开“收藏夹”，点击“＋”或“收藏当前网页”，填写名称、HTTP/HTTPS网址、分组和备注后保存。当前选中网页的标题与网址会预填。可编辑或删除收藏；搜索同时匹配名称、地址、分组、备注。

先选择“打开位置”，再点击收藏，将网址打开到该槽：已有网页会被导航替换，空槽会创建网页。横向收藏栏点击也使用当前选中槽位。

拖动收藏可调整前后顺序或跨组移动；拖动侧栏分组标题调整分组顺序。删除分组时收藏移入“未分组”，不会随分组删除。横向栏按相同分组和收藏顺序显示，不显示分组名称。

收藏拖入窗口标题栏或空槽有应用接收逻辑，但已加载网页内容区域由原生网页覆盖，拖放行为不一致，尚待完整鼠标验证。日常建议使用“打开位置”后点击收藏。

### 9.2 工作区和自动保存

顶部“保存工作区”或“工作区”中的“另存为工作区”，可保存当前网页地址组合、槽位布局、比例及每页音频和缩放。工作区支持加载、覆盖、重命名和删除。加载会应用相应页面组合；不是实时网页内存快照，不能恢复表单未提交内容、播放进度、滚动位置或完整导航历史。页面ID仍对应现有实例时实现可能复用该实例，不应依赖所有网页必定重新加载。

修改配置后通常约180ms防抖自动保存；原生浮窗等部分操作直接保存。设置中的“启动时恢复上次会话”默认开启；关闭后下次启动使用空的默认四宫格，收藏、命名布局和工作区仍保留。窗口系统位置、焦点、侧栏展开状态及内部放大状态未作为工作区快照保存。

当前存在旧快照覆盖新状态与快速退出前最后修改未确认落盘的风险。重要配置建议操作稳定后导出备份，不把“自动保存”视为零丢失承诺。

### 9.3 导入、导出和存储

在“设置”点击“导出 JSON”，选择保存位置。导出包含收藏、分组、自定义布局、命名工作区、上次会话及其他配置。导入前先备份；点击“导入 JSON”确认替换，选择有效配置文件后应用。导入是整份替换，不合并；取消对话框不导入。配置校验可拒绝非法格式，但部分重复ID与分组引用缺少完整一致性检查，建议只导入可信的本软件导出文件。

本地配置保存在用户应用数据目录内的 `config.json`。已打包程序保留 `MultiViewBrowser` 配置目录名，Windows通常为 `%APPDATA%\MultiViewBrowser`；源码运行通常为 `%APPDATA%\multiview-browser`，实际以Electron userData为准。写入使用临时文件替换，并在现有配置有效时保留 `.bak`；读取依次尝试主文件、备份文件，均无效则使用默认配置。备份是上一份有效配置，不是完整历史版本库。

JSON中含实际网址、收藏名称和备注，应妥善保管。网页登录由共享持久化浏览器会话保存，不随JSON导出Cookies；工作区也不备份登录凭据。

## 十、常见操作示例

### 同时观看四个网页并切换主画面

1. 选择“四宫格”，在四个槽位分别添加网页并输入网址。
2. 将希望主要观看的副网页编号拖到主窗口，交换后键盘焦点转到新的主网页，音频按主副规则重算。
3. 如需独看，点击“放大主窗口”；结束后点击“恢复分屏”。
4. 保存为工作区，以便以后恢复网址组合及设置。

### 两个副网页换位并继续输入

在2号网页中输入前，按住其编号拖到3号窗口。源网页移动到3号，焦点跟随该源网页；原3号网页移到2号。页面内容缩放跟随网页；副槽互换保留各自音频策略。

### 保存资料对照环境

选择左右双窗口，打开两个HTTP/HTTPS资料网址，拖动分割线调整宽度，分别使用Ctrl快捷键调整内容大小，再点击“保存工作区”命名。只想复用分屏比例而不带网页时，在布局面板中保存自定义布局。

## 十一、注意事项、已知限制与故障排查

| 现象                                     | 检查与处理                                                                                   |
| ---------------------------------------- | -------------------------------------------------------------------------------------------- |
| 启动脚本提示找不到exe                    | 确认完整构建位于脚本指定目录；源码仓库需先构建/打包                                          |
| 本机开发版无法启动，提示沙箱访问目录失败 | 本轮遇到Electron运行目录ACL问题；请由维护者核对目录权限。不要把禁用沙箱当作常规解决方法      |
| 添加网页或中键没有结果                   | 查看可见布局是否有空槽；切更多窗口布局或关闭不用的页面                                       |
| 切小布局后网页仍有声音或占资源           | 隐藏不是关闭；切回原布局并关闭网页，必要时总静音                                             |
| 收藏打开到错误或看不到的位置             | 在侧栏“打开位置”重新选可见槽位，再点击收藏                                                   |
| 页面没有声音                             | 依次检查总静音/0%、页面音量/静音、是否副槽自动静音、是否主窗口放大、网站播放器和系统混音器   |
| 新播放器不受音量控制                     | 属于已知媒体来源交接问题；尝试刷新网页并重设音量，检查实际输出；刷新会丢失网页临时状态       |
| 小窗口点击偏移或控件不可用               | 尝试响应式模式、恢复内容缩放或放大主窗口；复杂跨域iframe兼容性有范围限制                     |
| 摄像头、麦克风或通知不能使用             | 这些权限默认拒绝，界面未提供允许开关                                                         |
| 地址无法打开                             | 确认HTTP/HTTPS地址和网络；查看底部错误提示，尝试刷新；非网页协议不支持                       |
| 配置恢复异常                             | 检查恢复开关及导入文件；先备份用户数据，再请维护者核对主配置和备份，不直接覆盖仍需保留的文件 |
| 音量浮窗下半部看不到                     | 已知缺少屏幕边界保护；尝试移动窗口或使用更靠上位置的页面控制                                 |

多网页尤其多路直播会增加CPU、GPU、内存和网络负载。关闭不用的页面通常比仅隐藏更有帮助。本轮没有长时负载数据，不提供未经测量的性能指标或最大流数保证。

每次启动生成独立操作日志。项目内通常写入 `logs`，独立部署目录通常位于exe同级 `logs`，不可写时尝试用户数据目录的 `logs`。日志用于操作类别诊断，按白名单过滤，不应记录具体网址、标题、输入文字、密码或Cookies；它与包含实际地址的配置文件不同。报告问题可说明版本、操作步骤、涉及窗口编号和时间，并按需要提供脱敏日志；无需提交账号凭据。

本轮未完成真实站点登录聊天、中文输入法、视频全屏、真实系统拖放、多屏高DPI和长时间直播验收；这些属于待验证范围，不应视为已支持全部站点。补充在线依赖检查发现开发打包链6个moderate受影响包条目；仅生产依赖查询本次为0条，不能据此宣称整体无漏洞。更详细的问题证据和验证结果见独立的 [代码健康审计](CODE_AUDIT.md)。
